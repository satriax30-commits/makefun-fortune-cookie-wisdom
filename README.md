# makefun-fortune-cookie-wisdom

Entry for **Fortune Cookie Wisdom for Developers** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
original fortune-cookie line for a software developer to `/output/entry.txt`:

> The code you wrote at midnight will read like a stranger's by morning; be kind to strangers.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`MAKEFUN_OUTPUT_DIR`.
